## ⚡ My Latest Projects

### [Inscryption in JAVA](https://github.com/Guyomeuh/inscryption-tui)

Ported the indie game Inscryption in JAVA using a TUI interface for a University project. It uses the MVC model to represent the game and its gameplay. It does not represent the whole game, but only a portion of it.

Centered around OOP and implemented several design patterns such as Strategy, Observer, and Decorator.

### [StarGate Managing Tool](https://github.com/Guyomeuh/stargate-management)

Utilised C# .NET. It is a managing tool for a University project, helping the user visualize missions on specific planets. It gives the user the opportunity to add new missions and new events to the database. It also displays statistics about different missions.

Database-centered. Most of the stuff involved revolves around SQL requests and local DataSets.

### [Warhammer Dice Roll Simulator](link)

Utilised Java and Swing to simulate creation of an army in the Warhammer : Age of Sigmar wargame. It helps calculate the damages of an unit and can also simulate the whole combat phase.

Centered around MVC and Graphical User Interface. It's my very own project.

## ⚡ Mes derniers projets

### [Inscryption en JAVA](https://github.com/Guyomeuh/inscryption-tui)

Ce projet universitaire est essentiellement un portage du jeu indépendant Inscryption en JAVA utilisant une interface TUI. Il utilise le modèle MVC pour représenter le jeu et son gameplay. Il ne représente pas le jeu dans son intégralité, mais seulement une partie de celui-ci.

Le projet est principalement centré sur la programmation orientée objet et implémente plusieurs design patterns tels que Strategy, Observer et Decorator.

### [Outil de Gestion StarGate](https://github.com/Guyomeuh/stargate-management)

Encore une fois, un projet universitaire en C# .NET. Il s’agit d’un outil de gestion aidant l’utilisateur à visualiser des missions sur des planètes spécifiques. Il donne à l’utilisateur la possibilité d’ajouter de nouvelles missions ainsi que de nouveaux événements liés à une mission dans la base de données. Il affiche également des statistiques sur différentes missions.

Le projet est principalement centré sur les bases de données. La majorité des éléments impliqués tournent autour des requêtes SQL et des DataSets locaux.
